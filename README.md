# daliuren · 大六壬排盘断课技能

一个给 AI Agent 用的大六壬（六壬）排盘与断课 skill —— 按标准法起四课、立三传、布十二天将，输出可直接用于断语的成品盘。

适用于支持 `SKILL.md` 约定的 agent 框架（如 DeepSeek Harness / DSH）。

---

## 它解决什么问题

大六壬排盘规则繁琐：九宗门立三传、十二天将顺逆布、遁干六亲、空亡旬丁驿马，人工排盘极易出错；而断课又需要把排盘结果整理成结构化的判断依据。

这个 skill 把两件事一起做了：

- **排盘** —— `scripts/paipan.py` 用标准法一次输出：盘型、天盘、四课（含下神）、克贼、三传与取用法、六亲、遁干、三传天将、旬首旬空旬丁驿马、本命/行年上神、课体标签、十二将盘
- **断课** —— 按「五问十步」给出断语与应期，附类神表、应期五线索、空亡三层

---

## 快速开始

```bash
python scripts/paipan.py --day 辛亥 --jiang 辰 --shi 亥 --ming 申 --xingnian 子 --year 午
```

| 参数 | 说明 |
|---|---|
| `--day` | 日干支（必填，如 `辛亥`） |
| `--jiang` | 月将（按中气取） |
| `--shi` | 占时 |
| `--ming` | 本命 |
| `--xingnian` | 行年 |
| `--year` | 年支（用于孤辰寡宿） |

输入非法（非六十甲子 / 非地支）时报错并以退出码 1 结束。

## 核心内容

### 三条铁律

1. **第一课的下神＝日干本身**（寄宫只用于「定位干上神」）；课2下＝课1上神，课3下＝日支，课4下＝课3上神
2. **取将看「所临地盘宫」** —— 某传支乘什么将，看的是该天盘支所落的地盘宫里的将
3. **一课一问；再占有别** —— 短时反复＝渎；隔时再占＝观变

### 八步排盘

```
月将 → 占时 → 布天盘 → 起四课 → 九宗门立三传
     → 遁干六亲 → 十二天将 → 空亡旬丁驿马年命
```

九宗门的次序：贼克 → 比用 → 涉害 → 遥克 → 昴星 → 别责 → 八专，盘型特例先判 **伏吟** / **返吟**。

### 五问十步断课

**十步**：定题 → 类神 → 六处生克 → 神将 → 空亡/丁马/年命 → 课体 → 气数 → 应期与方位 → 断语 → 建议与退路

**五问**：① 缘起（发用位与六亲）② 过程（中传、神将）③ 结果（末传、生克日干）④ 应期 ⑤ 方位与人象

### 课体标签（脚本自动识别）

| 类别 | 涵盖 |
|---|---|
| 盘型类 | 伏吟、返吟、八专、别责、不备、昴星 |
| 课名类 | 元首、重审、知一、度厄、无禄、绝嗣、涉害、遥克（蒿矢/弹射） |
| 三传形状 | 进茹、退茹、进间、退间、三合局、元胎、稼穑 |
| 格局类 | 铸印、斩关、六仪、三奇、闭口、四绝、四墓 |
| 煞类 | 孤辰、寡宿 |

> 判定分歧的课体（励德、游子、乘轩、狡童、井栏射、独足、三光、六阳六阴、周而复始等）各家取法不一，脚本不自动标注，见 `references/keti.md` 末节人工核对。

## 安装到 DSH

```bash
git clone https://github.com/<your-name>/daliuren-skill.git ~/.dsh/skills/daliuren
```

Windows：

```powershell
git clone https://github.com/<your-name>/daliuren-skill.git "$env:USERPROFILE\.dsh\skills\daliuren"
```
