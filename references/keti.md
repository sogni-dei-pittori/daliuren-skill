## 一、盘型类（先判）
| 课体 | 判定 | 断义 |
|---|---|---|
| 伏吟 | 月将与占时同支（d=0），天盘各坐本家 | 静、藏匿、旧事；乙癸有克，余则阳日自任/阴日自信 |
| 返吟 | 将与时相冲（d=6），天盘各坐对冲 | 反复不定、来去、宜反旧事；无克＝无亲（取支驿马→支上→干上） |
| 八专 | 干寄宫＝日支（丁未、癸丑、甲寅、己未、庚申） | 人宅同体、局小自守、专注自身；无克则阳日干上顺数三神、阴日支阴逆数三神 |
| 别责 | 课不备（课1＝课4 为阴不备，课2＝课3 为阳不备）且无克无遥 | 借人而成；**刚日取干合之寄宫上神**（丙合辛、辛寄戌，取戌上神；例丙辰日干上午→亥午午）、**柔日取支三合前位上神**（如酉日取地盘丑位上神，粹言自注非用丑也），中末俱取干上神 |
| 不备（阳/阴） | 课1＝课4 为阴不备、课2＝课3 为阳不备（八专除外） | 干支阴阳二神缺一课；有克贼照常论，无克无遥则入别责 |
| 昴星 | 四课齐备、无克无遥 | 惊险宜静；阳日虎视（初地盘酉上神、中支上、末干上），阴日冬蛇掩目（初天盘酉下神、中干上、末支上） |
